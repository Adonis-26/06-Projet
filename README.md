# Sophie Bluel - Architecte d'Intérieur

Application web développée dans le cadre du parcours Développeur Front-End d'OpenClassrooms.

Le projet consiste à créer le portfolio en ligne d'une architecte d'intérieur, avec une galerie dynamique alimentée par une API REST et un espace administrateur permettant la gestion des projets.

---

# 📋 Description

**Sophie Bluel** est une application permettant de présenter les réalisations d'une architecte d'intérieur.

Les travaux affichés dans la galerie sont récupérés depuis une API. Un administrateur authentifié peut gérer les projets via une interface dédiée :

- Ajout de nouveaux projets
- Suppression de projets existants
- Gestion dynamique de la galerie
- Authentification sécurisée via API
